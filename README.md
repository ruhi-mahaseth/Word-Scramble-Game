# Word Scrambler Game

A simple Word Scrambler game built using HTML, CSS, and JavaScript.

## About the Project

The Word Scrambler is a simple web-based game where the player has to guess the correct word from a scrambled version of the word.

## Features

- Simple and user-friendly interface
- Random scrambled words
- Input field for entering the answer
- Interactive buttons
- JavaScript-based game logic
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `main.html` in a web browser.
4. Start playing the game.
